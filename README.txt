HOW TO OPEN
1. Extract this ZIP in Acode or your phone's file manager.
2. Open index.html in Acode preview/browser.
3. Keep index.html, style.css, script.js, birthday-wish.m4a, romantic-instrumental.wav and photos/ together.
4. Internet is used only for Google Fonts and the optional confetti animation. Core pages and sounds are local.
